# Magic Battle — Releases

This repository hosts **release APK downloads only** for the Magic Battle Android game.

- The **source code lives in a private repository** — it is not published here.
- The app checks this repo's Releases through the public GitHub API (no account, no token, no tracking).
- Android only installs an update signed with the app's own key, so only APKs published here (and signed by the developer) can update the installed app.

## Install / Update

1. Download the newest `MagicBattle-vX.Y.Z.apk` from [Releases](https://github.com/abolfazlebrahimi1791-cloud/magicbattle-releases/releases).
2. Or simply use **Main menu → Check for update** inside the app (version 2.14+) — it downloads and offers the install automatically.
